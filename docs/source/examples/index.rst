Examples
========

This section collects end-to-end REAX examples.

Autoencoder
-----------

A Flax Linen autoencoder trained on MNIST, demonstrating the full
:class:`~reax.Module` lifecycle (``configure_model``, ``training_step``,
``configure_optimizers``) and :class:`~reax.Trainer` usage. Available at
`examples/autoencoder.py <https://github.com/camml-lab/reax/blob/develop/examples/autoencoder.py>`_
on GitHub.
